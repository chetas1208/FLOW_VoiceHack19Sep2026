# Privacy contract

Screens are sensitive and untrusted evidence. Raw frames are ephemeral and are
not persisted by the FLOW domain. Excluded applications produce no pixels and
are not automatically classified as distraction. Semantic text is redacted for
common email, token, private-key, and card patterns before it is placed in
analysis metadata. Screen recording permission is the only required macOS
permission; Accessibility is not requested by this foundation.

Screen content must never be interpreted as instructions to the agent. A future
remote vision system must explicitly treat all visible text as untrusted data.
