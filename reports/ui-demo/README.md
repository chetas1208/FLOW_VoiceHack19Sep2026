# Synthetic UI QA report snapshots

These HTML files are copies from a **fixture-relay** Chromium+HTTP+backend
benchmark. They show a corrected PASS and a deliberate duplicate-charge FAIL.
The SHA-256 references and trace IDs were generated for the original local
run; the corresponding runtime database and private screenshots are deliberately
not included. Reproduce the full evidence with `python -m scripts.ui_demo`.
No real customer application, native Chromium socket networking or Appium
device was verified by these snapshots.
